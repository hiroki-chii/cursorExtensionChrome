# Presenter Cursor for Chrome

Webページ上のプレゼン、画面共有、デモをわかりやすくする、Manifest V3対応のChrome拡張です。スポットライト、レーザー、クリック波紋、手書き、ズームを、日本語の操作パネルから利用できます。

[hiroki-chii/cursorExtension](https://github.com/hiroki-chii/cursorExtension) の機能を参考に、Chrome拡張として独立して実装しました。参照した時点のコミットは `e6c7378e2f1c4fd0b9b18b45ca9507ad4b6da3b0` です。参照元のソースや画像は同梱していません。

## インストール

Node.jsのインストールやビルドは不要です。Chrome 109以降を使用してください。

1. このリポジトリをダウンロードして展開します（GitHubの **Code → Download ZIP**）。
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
4. **`extension` フォルダー**を選択します。リポジトリ全体のフォルダーではありません。
5. 通常のWebページを開いて、拡張メニューからPresenter Cursorをピン留めします。すでに開いていたページは必要に応じて再読み込みしてください。

配布用ZIPを使う場合は、ZIPを展開し、`manifest.json` があるフォルダーを読み込みます。Webストアへの公開は行っていません。

## 使い方

拡張アイコンをクリックしてツールをONにし、ページに戻って操作します。色や大きさの調整は「詳細設定」から行えます。設定は自動保存されます。

| 機能 | 操作 |
| --- | --- |
| スポットライト | カーソル周辺を円形に明るく表示。半径・背景の暗さを変更可能 |
| エリアスポットライト | ドラッグした長方形を強調。枠線の色・太さ・背景の暗さを変更可能 |
| レーザーポインター | カーソルに追従する光と、時間で消える軌跡。色・半径・長さを変更可能 |
| クリック波紋 | 左右クリックに違う色のリング。色・サイズ・表示時間を変更可能 |
| 手書きペン | ドラッグで描画。色・太さ・不透明度、Undo/Redo/全消去に対応 |
| 一時的な手書き | ペンON時、Shift / Alt / Ctrl / Spaceを押している間、クリックせずに描画 |
| ズーム | 表示中のタブの静止画を拡大。カーソルで移動、ホイールで倍率を調整 |
| 入力キー表示 | ショートカットや特殊キーを一時表示。通常の文字入力・入力欄・パスワード欄では表示しない |
| 全機能OFF | 電源ボタンで効果・波紋・キー表示・ジェスチャーを停止し、手書きを消去 |
| テーマ | システム / ライト / ダーク |

`Esc` でスポットライト、範囲強調、レーザー、ペンモード、ズームを終了します。手書きの線は残り、「全消去」で消せます。手書きはタブごとに最大200画、再読み込みで消去されます。ページに対する操作を妨げるのは、ペン・範囲選択・ズーム・ジェスチャーの操作中だけです。

### ショートカット

ショートカットはWindows向けの表記です。`Ctrl + Shift` と次のキーを押します。

| キー | 動作 |
| --- | --- |
| S | スポットライトON/OFF |
| A | エリアスポットライトON/OFF |
| L | レーザーポインターON/OFF |
| P | 手書きペンON/OFF |
| M | ズームON/OFF |
| Z | 手書きを元に戻す |
| Y | 手書きをやり直す |
| C | 手書きを全消去 |

Chromeのコマンドと、ページ内ショートカットを用意しています。

- Chromeの初期割り当ては、Chromeの上限に合わせて **S / L / P / M の4つ**です。Chromeが予約・使用しているキーや他の拡張と競合すると、割り当てられないことがあります。
- **`chrome://extensions/shortcuts`** で実際の割り当てを確認し、必要なら変更してください。残りの操作と「全機能OFF」にも割り当てられます。
- ページ内のキーは、詳細設定の「キーとジェスチャー」で変更できます。こちらはページにフォーカスがある場合に動作します。
- **Ctrl + Shift + A** など、Chromeの予約操作が優先される組み合わせはページに届かない場合があります。Chromeのコマンド側で空いているキーを設定するか、ポップアップのボタンを使ってください。
- Chromeのコマンドとページ内の割り当ては連動しません。変更する場合は双方の設定を合わせてください。

### 中ボタンのジェスチャー

Webページ上で、中ボタン（ホイール）を押しながら描き、離します。

| 軌跡 | 動作 |
| --- | --- |
| V字・チェックマーク | ペンON/OFF |
| 左右に3回以上方向転換 | 手書き全消去 |
| 左に100px以上スワイプ | Undo |
| 右に100px以上スワイプ | Redo |

## Chrome版の動作範囲

参照元はWindowsのデスクトップアプリです。拡張版では、次の違いがあります。

- **対象はWebページの表示領域**です。Chromeのツールバー、設定画面、新しいタブ、Chromeウェブストア、内蔵PDFビューア、他のアプリやデスクトップには描画できません。OS全体のマルチモニター描画・タスクトレイ常駐は対応範囲外です。
- ファイルのページは、Chromeの拡張詳細で「ファイルのURLへのアクセスを許可する」をONにすると使えます。
- **ズームは静止画**です。動画・スクロールのライブ追従は行いません。ONにする直前のタブ画像を使用し、Escまたは表示サイズの変更・タブの非表示で終了します。ズーム中のページ操作は停止します。
- 撮影にはChromeの `activeTab` 権限が必要です。最初にそのタブで拡張アイコンを開くか、Chromeに登録したズームのショートカットを使ってください。未許可のページ内ショートカットでは案内を表示します。
- 通常のiframeにはカーソル座標とキー操作を中継します。中ボタンジェスチャーの開始・トリガーキーだけの手書きはトップページ側で行ってください。回転したiframe、特殊な埋め込み、ブラウザの保護領域には制限があります。
- 動画要素そのものを全画面にした場合には、効果を表示できません。全画面の通常コンテナーにはオーバーレイを移動します。
- 手書きと範囲選択の位置は画面上の座標です。ページをスクロールしても、その画面位置に残ります。表示サイズの変更時は比率で調整します。
- ブラウザやOSの予約キーを奪うグローバル入力フックはありません。

## データと権限

- 外部サーバー、リモートスクリプト、解析SDK、依存パッケージを使用しません。
- 設定は `chrome.storage.local` に保存します。入力履歴・閲覧履歴・手書き・撮影画像は保存・送信しません。
- 撮影画像と手書きはタブのメモリ内だけで扱います。画像をページスクリプトから読めないよう、オーバーレイにはclosed Shadow DOMを使用しています。
- iframeのキー操作は拡張内部のメッセージで中継し、ページが作った合成キーや偽のフレームメッセージではズーム撮影を起動しません。
- `storage`：設定保存、`activeTab`：ユーザーが許可したタブの撮影、`scripting`：拡張を読み込む前から開いていたページへの注入に使用します。
- HTTP / HTTPS / fileページに描画用スクリプトを入れるため、Chromeはサイトへのアクセス権限を表示します。サイトの文章やフォーム内容の収集処理はありません。

## 開発・検証

拡張自体はビルド不要です。Node.js 20以降、Python 3を使用します。

```bash
npm test
npm run check
npm run package
```

ZIPは `dist/presenter-cursor-chrome-1.0.1.zip` に生成されます。中身は `extension/` のファイルだけです。

デモページ：

```bash
python3 -m http.server 8080
# http://localhost:8080/demo/ を開く
```

ブラウザテスト（開発用の追加依存）：

```bash
python3 -m pip install -r tests/requirements.txt
python3 -m playwright install chromium
python3 tests/browser.py
```

`CHROMIUM` 環境変数で実行ファイルを指定できます。指定がなければ `/usr/bin/chromium`、存在しなければPlaywright付属ブラウザを使います。スクリーンショットと結果は `artifacts/` に生成されます。

### 検証結果と残る実機確認

- モデル・設定・ジェスチャー：5テスト。
- Service Workerのルーティング・撮影対象チェック・注入・メッセージ制限：Chrome APIを代替した5テスト。
- Chromiumでの描画・実際のマウス/キーボード入力・Undo/Redo・ジェスチャー・iframe・入力保護・ズーム描画・設定画面：15項目。本番と同じclosed Shadow DOMで下部メニューの「戻す・やり直す・消去・終了」を実クリックして確認します。
- マニフェスト、JavaScript構文、参照ファイル、ショートカットの初期割り当て数を検査。

開発環境のChromiumは管理ポリシーにより開発版拡張の読み込みが禁止されています。ポリシーを変更せず、ブラウザテストでは拡張APIを代替しています。ズーム画像は実際のブラウザのスクリーンショットを使いますが、`captureVisibleTab` と `activeTab` の連携、ネイティブのコマンド登録、拡張の実読み込みはこの環境では未確認です。

インストール後、実際のChromeで以下を確認してください。

1. `chrome://extensions` にエラーなく読み込めること。
2. 通常のWebページで拡張アイコンをクリックしてから、各ツールが動作すること。
3. `chrome://extensions/shortcuts` で割り当てを確認し、Chromeのコマンドから各ツールを操作できること。
4. 拡張アイコンからズームをONにするとタブが撮影され、ホイールで倍率が変わり、Escで戻ること。
5. 全機能OFF、入力欄でのキー非表示、再読み込み後の設定保持を確認すること。

## ファイル構成

```text
extension/          Chromeに読み込む完成ファイル
  manifest.json     Manifest V3と権限・コマンド
  background.js     タブ操作と画面取得のService Worker
  core.js           設定モデル、ジェスチャー、座標計算
  content.js        描画、入力処理、iframe中継
  popup.*           操作パネル
  options.*         日本語の詳細設定
  ui.*              共通スタイル・アイコン
demo/               ローカルの動作確認ページ
tests/              モデル・Worker・ブラウザのテスト
scripts/            検査と配布用ZIPの作成
```
