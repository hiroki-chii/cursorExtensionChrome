# ストアの「プライバシーへの取り組み」入力用

対象：Presenter Cursor v1.0.2。申告内容は、同梱コードを読んで作成しています。別の機能や外部通信を追加した場合は申告を更新してください。

## 単一用途の説明

以下を貼り付けます。

> Webページでのプレゼンテーション、操作説明、画面共有を見やすくするため、カーソルの強調、手書きの注釈、表示中のタブ画像の拡大、操作の一時的な可視化を提供します。これらは、閲覧中のWebページ上で説明内容への注意を促すという一つの目的のための機能です。

## 権限の説明

### storage

スポットライトの半径や暗さ、レーザーやペンの色・太さ、クリック波紋、キー表示、ジェスチャー、ショートカット、表示テーマなどの設定を、端末内のchrome.storage.localに保存するために使用します。画面画像、手書き、閲覧履歴、キー入力の履歴はこのストレージに保存しません。

### activeTab

ユーザーが拡張アイコンやChromeに登録されたコマンドで操作したタブで、現在のタブ情報の確認と、ズーム用の表示領域の撮影に使用します。captureVisibleTabで取得した画像をタブ内のメモリで拡大表示し、画像をサーバーへ送信したりファイルに保存したりしません。

### scripting

拡張をインストールする前から開いていたWebページなどに、同梱の描画用スクリプトがまだ存在しない場合、ユーザーが操作パネルを利用した時点で注入するために使用します。注入するのは拡張パッケージに同梱したcore.jsとcontent.jsだけです。

### ホスト／サイトへのアクセス（表示された場合）

HTTP・HTTPSのWebページと、ユーザーが別途アクセスを許可したfileページで、スポットライト、レーザー、クリック波紋、手書き、ジェスチャー、キー表示を利用するためです。ページ上でカーソルの座標、クリック、キーイベントを処理し、描画用オーバーレイを表示します。iframeを含むページ内でもポインターが追従するように中継します。ページの文章や入力欄の値を収集して外部へ送信する処理はありません。幅広いページで継続して同じ補助機能を利用するため、content_scripts.matchesにhttp://*/*、https://*/*、file:///*を指定しています。

注：現在のmanifestにはhost_permissionsという項目はありませんが、content_scriptsの対象サイトについて説明が求められた場合に、この文章を使用します。

## リモートコード

**使用しない（No, I am not using remote code）**を選択します。

補足欄がある場合：JavaScript、HTML、CSS、画像はすべて拡張パッケージ内に同梱しています。外部スクリプト、CDN、eval、外部API、解析SDKは使用しません。

## データ使用の申告

「外部送信しない」ことと「データを扱わない」ことは異なります。公式FAQは、端末内だけで処理・保存するデータも開示対象としています。**「一切のデータを扱わない」とは申告しません。**

現在の実装に合わせた申告案は次のとおりです。管理画面の実際の項目名・説明と照合して入力してください。

| データの種類 | 申告案 | 取り扱い |
| --- | --- | --- |
| ウェブサイトのコンテンツ / Website content | 対象として申告 | ユーザーがズームを実行したときの表示領域を画像として端末内で一時処理します。画像に表示中の情報が含まれます。 |
| ユーザーのアクティビティ / User activity | 対象として申告 | ポインター座標、クリック、ジェスチャー、描画、必要なキーイベントを、表示や入力判定のため端末内で一時処理します。 |
| ウェブ履歴 / Web history | 対象として申告 | 現在のタブのURLを、対応するページかどうかの判定に一時使用します。閲覧履歴の一覧の取得・蓄積・送信はしません。現在のURLも含むという項目説明に合わせた保守的な申告です。 |
| 個人を特定できる情報、健康、金融、認証情報、個人的な通信、位置情報 | 専用の収集項目としては選択しない案 | これらの情報を専用に抽出する処理や、認証、決済、位置取得の処理はありません。ただし表示中の情報がズーム画像に含まれる可能性は、ウェブサイトのコンテンツとプライバシーポリシーで説明します。管理画面が画像内の付随情報も個別に申告するよう求める場合は、その定義に従います。 |

取り扱い方法を記述できる場合：

> 対象タブの現在のURL、ポインター座標、クリック、ジェスチャー、必要なキーイベント、手書きの注釈、ユーザーが実行したズーム用の表示領域画像を端末内だけで処理します。URLや操作の履歴を保存せず、画面画像と注釈はタブのメモリ内だけで使用します。開発者・第三者への転送、広告利用、販売、アクセス解析はありません。通常の文字キーと入力欄内の操作はキー表示の対象から除外します。画面画像にはその時点で表示されている内容が含まれます。

## データ使用に関する確認欄

現在の実装では、次の内容に対応します。管理画面の原文を読んでチェックしてください。

- 許可された用途を除き、ユーザーデータを第三者へ販売・転送しない。
- 拡張の単一用途と無関係な目的でユーザーデータを使用・転送しない。
- 信用力の判断や融資判断にユーザーデータを使用・転送しない。
